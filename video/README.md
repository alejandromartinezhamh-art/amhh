# Vídeos con Remotion

Proyecto [Remotion](https://www.remotion.dev) para vídeos verticales (9:16).

- `npm run dev` — abre Remotion Studio para previsualizar y editar.
- `npm run render` — renderiza `NegocioParalelo` a `out/negocio-paralelo.mp4`.

La composición está en `src/NegocioParalelo/` (escenas, subtítulos animados y fondo).
Las fuentes (Anton y Montserrat) están en `public/fonts` para que el render funcione sin conexión.

El último render de prueba está en `renders/negocio-paralelo.mp4`.
